global-bundle.p7bから
対象ルート証明書だけを登録する

Windowsの画面を使い、バンドルを開いて対象証明書を選び、現在のユーザーの証明書ストアへ登録します。

対象例：東京リージョン / rds-ca-rsa2048-g1　｜　更新日：2026年11月19日

作業の流れ

AWSの global-bundle.p7b を証明書ビューアーで開き、対象ルートを一覧から選択します。選んだ証明書の画面からインストールウィザードを起動し、その証明書1件だけを登録します。

登録先：証明書 - 現在のユーザー → 信頼されたルート証明機関。管理者権限は通常不要です。
注意：global-bundle.p7b を証明書管理画面から一括インポートしないでください。この手順では一覧から対象ルート1件を選んでインストールします。中間証明書は登録しません。

操作手順

2

global-bundle.p7bを開き、対象ルートを選ぶ

エクスプローラーで配布された global-bundle.p7b を右クリックし、「プログラムから開く」→「Crypto Shell Extensions」（暗号化シェル拡張）を選びます。証明書一覧が表示されたら、次の条件をすべて満たす1件を選びます。

  • 名前：Amazon RDS ap-northeast-1 Root CA RSA2048 G1
  • 発行先（Subject）と発行者（Issuer）が同じ（自己署名ルート）
  • 詳細の拇印：D790 BBB6 61BA FA41 0182 9F10 3D63 9BEF A300 F9A4

名前や拇印が一致しない場合は、インストールせず管理者に確認してください。証明書の有効期間内であることも確認します。

拇印は、選択した証明書を開き「詳細」タブ→「拇印」で確認します。表示値に空白がある場合は取り除いて照合します。
3

選んだ証明書を開く

証明書一覧で、手順2で拇印を確認した1件をダブルクリックします。開いた証明書の画面で、名前、発行者、拇印が選択時の内容と一致することをもう一度確認してください。

4

選択した証明書のインストールを開始する

証明書の画面で「証明書のインストール」をクリックします。証明書のインポートウィザードが開きます。

5

現在のユーザーの信頼されたルートへ登録する

ウィザードで「現在のユーザー」を選択します。証明書ストアの選択画面では「証明書をすべて次のストアに配置する」を選び、「信頼されたルート証明機関」を指定して完了します。

「ローカル コンピューター」や「コンピューター アカウント」は選びません。ウィザードに「現在のユーザー」が表示されない場合は作業を止め、管理者に確認してください。
6

登録結果と拇印を確認する

Win + R を押し、certmgr.msc と入力してEnterを押します。タイトルが「証明書 - 現在のユーザー」であることを確認し、「信頼されたルート証明機関」→「証明書」に対象ルートが表示されるか確認します。証明書を開いて拇印が手順2の値と一致すれば登録完了です。

対象証明書が1件表示され、拇印が一致すれば完了です。Power BI Desktopなど接続アプリを完全に終了し、起動し直してから再接続します。

中止して管理者へ確認する場合

  • 対象名または拇印が一致しない
  • 自己署名ルートであることを確認できない
  • 有効期間が切れている、またはPCの日付が正しいか判断できない
  • 証明書の選択やインストール画面がこの説明と異なる
「サーバー証明書を検証しない」など、証明書検証を無効にする設定は行わないでください。

対象例：rds-ca-rsa2048-g1 / 拇印 D790BBB661BAFA4101829F103D639BEFA300F9A4。配布時はスクリプトの設定と一致するか確認してください。
